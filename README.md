# カコモと学ぶ 決算チャレンジ 衛生費編

加古川市 令和7年度一般会計決算「衛生費」(約74.9億円)を、クイズと予算判断
シミュレーションで学べる単一HTMLファイルのPWAです。

## この款のポイント

- 決算総額(約74.9億円)は保健衛生費(約50.9億円)と清掃費(約24.0億円)の2項
- seika_houkokusho側の事業一覧は29件、合計約31.8億円でカバー率は約42%
- 事業一覧には出てこない支出として、加古川市民病院機構への運営費負担金
  (約16.7億円)があり、29事業のどれよりも大きい金額
- 事業名が重複するケース(「予防接種事業」が乳幼児等向け・高齢者等向けの
  2本立てで登場)を発見し、所管課(育児保健課/地域医療課)で区別してカード化
- 29事業のうち5事業(予防接種事業2本・市町母子保健事業・妊娠出産子育て
  支援事業・大気環境保全事業)は法律に基づく法定事業

## 構成

1. **入口クイズ層**(40問、2択): 基礎知識5問(病院機構負担金・事業名重複ネタ含む)
   +予算vs決算29問+特別トリビア6問(マテリアルリサイクル推進施設整備事業・
   予防接種事業(高齢者等)の急増理由、太陽光補助金の急減理由、し尿終末処理の
   ベンダー集中、高砂市との広域ごみ処理、加古川医師会が6事業にまたがり
   合計約9.35億円を受給している事実)
2. **本編シミュレーション層**: 29事業。法定5件/裁量24件に分類
3. **答え合わせ層**: 未実装(他の款と同様)
